# 温暖小屋 · 微信分享版

这是无需安装、无需服务器的网页游戏包。将解压后的整个文件夹发送给朋友，不要只发送其中一个 HTML 文件。

## 在手机上打开

1. 在微信中接收 `温暖小屋-微信分享版.zip`，保存到手机。
2. 在手机文件管理器中解压 ZIP，保持解压出的文件夹结构不变。
3. 打开解压文件夹里的 `index.html`，选择手机浏览器打开，即可进入小屋并切换房间。

部分手机不会直接运行从微信接收的本地 HTML 文件；如果打开后只是显示源码，或房间图片/音乐无法加载，请把这个文件夹部署到支持 HTTPS 的静态网站，再将网站链接发给朋友。

## 重要说明

- 这是可分享的手机网页游戏，不是微信小程序卡片；本地 ZIP 文件不能变成微信内直接启动的小程序链接。
- 角色、造型、猫咪状态和音乐保存在每台设备自己的浏览器中，不会自动共享。
- 卧室音乐在切换房间时会继续播放；接收者需要在自己的设备上选择音乐。
- 要通过微信小程序卡片启动，需要注册 AppID、用微信开发者工具上传体验版或提交审核并发布。
